# 📚 Student Task & Assignment Manager

A responsive web application designed to help students organize assignments, manage deadlines, track pending tasks, and monitor their academic progress.

## 🚀 Features

- Add new assignments.
- Enter assignment name and subject.
- Set assignment deadlines.
- Set priority levels (Low, Medium, High).
- View all assignments.
- Mark assignments as completed.
- Change completed tasks back to pending.
- Delete assignments.
- Filter tasks by All, Pending, and Completed.
- View total, pending, and completed task counts.
- Automatically save tasks using browser Local Storage.
- Responsive design for desktop and mobile devices.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Application functionality.
- **Local Storage** – Saving assignment details in the browser.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Enter assignment details.
5. Add, complete, filter, or delete assignments.

## 🌐 GitHub Pages Deployment

1. Open your GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select the `/ (root)` folder.
7. Click **Save**.

Your website will be published using GitHub Pages.

## 💾 Data Storage

This project uses browser Local Storage to save assignment details. Data remains in the browser on the device where it was entered. It is not stored in an online database.
